# 社区生活服务小程序前端功能梳理及后端需求

本文档梳理了小程序前端已有的核心功能模块，并据此整理了对应的后端 API 需求及逻辑实现要点。

---

## 1. 核心业务模块

### 1.1 首页与分类 (Index & Classify)
*   **前端功能**：
    *   顶部 Tab 切换（惠民卡、本地好物、首页、本地集市）。
    *   金刚区分类展示（整理收纳、家政服务、美业等）。
    *   Banner 位展示与跳转。
    *   推荐位列表（技工列表、服务商列表、集市店铺）。
*   **后端需求**：
    *   `GET /index/config`：获取首页配置（Banner, 金刚区分类, 快捷入口）。
    *   `GET /index/recommendations`：获取首页推荐数据（技工、服务商等）。
    *   `GET /categories`：获取全部分类树状结构。

### 1.2 本地集市 (Market)
*   **前端功能**：
    *   基于地理位置的店铺排序。
    *   店铺详情展示（商品列表、评价、资质）。
    *   商品分类联动滚动。
    *   本地购物车（支持增减商品、清空、总价计算）。
*   **后端需求**：
    *   `GET /market/shops`：分页获取附近店铺（支持经纬度、分类、排序过滤）。
    *   `GET /market/shops/{id}`：获取店铺详细信息。
    *   `GET /market/shops/{id}/goods`：获取店铺内商品列表。
    *   `POST /market/cart/sync`：同步本地购物车到服务端。

### 1.3 邻里互动社区 (Community)
*   **前端功能**：
    *   帖子列表展示（支持热门话题、活动、邻里互动）。
    *   发布动态（文字 + 多图上传）。
    *   点赞与评论交互。
    *   话题参与。
*   **后端需求**：
    *   `GET /posts`：分页获取动态列表。
    *   `POST /posts`：创建新动态（关联话题、地理位置）。
    *   `POST /posts/{id}/like`：切换点赞状态。
    *   `POST /posts/{id}/comments`：发表评论。
    *   `GET /topics/hot`：获取热门话题列表。

### 1.4 一键发布与邻里帮帮 (Order Publish)
*   **前端功能**：
    *   需求发布（地址、时间、内容描述、图片）。
    *   邻里帮帮快捷入口（代取、接送等）。
*   **后端需求**：
    *   `POST /orders/publish`：创建发布订单。
    *   `GET /orders/categories`：获取发布分类（代取、跑腿等）。

### 1.5 联盟商城 (Benefit Alliance)
*   **前端功能**：
    *   京东/拼多多联盟商品展示。
    *   商品详情跳转。
*   **后端需求**：
    *   `GET /alliance/products`：获取外部联盟商品数据（需对接三方 API 或同步数据）。

---

## 2. 用户与入驻模块

### 2.1 用户中心 (User Center)
*   **前端功能**：
    *   用户基本信息展示（头像、昵称、手机号、角色标签）。
    *   钱包余额、积分、优惠券展示。
    *   地址管理（增删改查、地图选点）。
    *   订单入口（到家、集市、帮帮等）。
*   **后端需求**：
    *   `GET /user/profile`：获取用户完整资料。
    *   `POST /user/update`：更新用户信息。
    *   `GET /user/addresses`：获取收货地址列表。
    *   `POST /user/addresses`：保存/更新地址（含经纬度存储）。
    *   `GET /user/coupons`：获取我的优惠券。

### 2.2 角色入驻 (Join)
*   **前端功能**：
    *   技工、集市商家、服务商入驻申请表单。
    *   资质证明上传（身份证、营业执照、作品图）。
*   **后端需求**：
    *   `POST /worker/apply`：提交技工入驻申请。
    *   `POST /merchant/apply`：提交商家入驻申请。
    *   `POST /service/apply`：提交服务商入驻申请。

---

## 3. 通用基础能力

### 3.1 身份认证 (Auth)
*   **前端功能**：
    *   微信一键登录、获取手机号。
*   **后端需求**：
    *   `POST /auth/wx-login`：微信 Code 换取 Token。
    *   `POST /auth/update-phone`：解密微信手机号并绑定。

### 3.2 文件处理 (File)
*   **前端功能**：
    *   图片上传。
*   **后端需求**：
    *   `POST /upload`：通用文件上传接口（返回服务器相对路径）。

### 3.3 定位与搜索 (Geo & Search)
*   **前端功能**：
    *   获取当前位置坐标。
    *   全局搜索（店铺、服务、商品）。
*   **后端需求**：
    *   `GET /search/global`：多端统一搜索接口。
    *   `GET /geo/communities`：获取附近小区列表。

---

## 4. 数据库设计建议（核心表）

1.  **Users**：存储用户基本信息、角色权限、余额积分。
2.  **Addresses**：存储地址、联系人、经纬度。
3.  **Shops**：集市店铺信息、评分、经营类目。
4.  **Goods**：集市商品、库存、价格。
5.  **Posts**：社区动态、图片集。
6.  **Comments/Likes**：社交互动记录。
7.  **Orders**：所有类型的订单记录（需区分业务类型）。
8.  **Applies**：各种角色的入驻审核申请单。
