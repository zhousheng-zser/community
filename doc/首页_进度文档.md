# “首页” 模块进度文档

## 整体进度概览
“首页”是社区小程序最核心的引流和功能分发页面。前端采用了顶部四个子标签（惠民卡、本地商城、首页、本地集市）切换的架构。
目前，前端 UI 框架已基本构建完成，使用了大量的本地 Mock 数据进行页面展示。后端的分类查询、热门服务、Banner拉取等接口已具备，正在进行接口联调（旧接口切换阶段）。

## 子页面进度拆解

### 1. 首页 (默认核心展示区)
- **前端进度 (基本完成 UI，联调中)**
  - 已完成顶部定位、搜索框、九宫格金刚区、Banner 轮播。
  - 已完成各种业务区块UI："邻里帮帮"、"小区热卖榜" (横向滑动)、"直约服务商" 和 "直约技工"。
  - 核心逻辑基于本地假数据 (`categoryList`, `quickActions`, `hotList`, `merchantList` 等) 展示，并注释了原请求 `api/wx/index`，暂留接口替换空间。
- **后端进度 (接口就绪)**
  - 根据 `API接口文档.md`，`/api/v1/core/banners` 获取轮播图、`/api/v1/core/categories` 获取服务类目、`/api/v1/core/services/hot` 获取热门服务均已开发完成（第三阶段）。
  - 有待前端解除假数据并将真实接口绑定。

### 2. 惠民卡 (生活消费折扣区)
- **前端进度 (纯 UI 静态实现)**
  - 页面结构已完成：包含本地生活九宫格分类、开通惠民卡卡片、商品流横排以及下方瀑布流筛选。
  - 数据源均来自 `index.js` 中的写死数据 (例如 `fukaLocalList`, `fukaGoods`)。
- **后端进度**
  - 后端暂时没有明确看到专属于“惠民卡”商品折扣业务的接口。该阶段属于前端预研或是后续规划。

### 3. 本地商城 (电商推客与带货区)
- **前端进度 (UI 高度完善，静态展示)**
  - 实现了六大核心模块的 UI：顶级海报轮播区、五大金刚区、导购窗、每日上新与热卖榜、双层结构直播推介窗（本地特产矩阵轮播+卡片）、热门带货视频（横向滚动+底部定制滑动胶囊槽指示器）、周期性主推与长效分类 feed 流。
  - 还实现了简单的假分页加载逻辑（`onReachBottom` 触底生成新一页假数据）。
- **后端进度**
  - 电商选品和高佣金商品的推广接口暂未在 API 文档中体现，前端目前靠 `index.js` 中极冗长的静态数据驱动。

### 4. 本地集市 (周边社区集市商圈)
- **前端进度 (UI静态实现与交互规划)**
  - 已完成商圈分类导航、Banner位、以及周边商家卡片流。
  - 列表交互上：不仅显示商家信息，还支持在商家卡片内进行商品横向滚动展示。
  - “本地集市”入住功能入口在用户页，入住表单的发布请求在前端逻辑有待链接。
- **后端进度 (联接入驻完成，待展示层)**
  - 商家入驻接口：`POST /api/v1/market/apply` 以及相关数据表（`market_applications`）已于2026年6月迭代完成并通过了联调。
  - 至于获取周边商家商品列表等展示端接口目前还在对接或开发排期中。

## 联调及后续关键事项
1. **订单接口联动**：页面底部悬浮按钮或弹窗需要用户验证（绑定手机号码等），登录鉴权模块（`/api/v1/auth/login` 等）已完成，正待前端进一步封装请求头。
2. **帮帮一键发布挂载**：首页已经存在全局悬浮按钮 “一键发布”，对应跳转到 `/pages/order-publish/order-publish`。而后端近期已完成了帮帮发布接口 (`POST /api/v1/orders/publish`) 的需求，只需确保跳转后该页正确发起请求。
