## 一、用户注册登录完整链路测试

### 链路概述

```
微信授权登录 → 获取Token → 绑定手机号 → 绑定小区 → 更新个人信息 
→ 验证Token有效性 → 查看个人中心 → 退出登录
```

### 1.1 完整链路测试脚本

```bash
#!/bin/bash
# 用户注册登录完整链路测试脚本

BASE_URL="${BASE_URL:-http://127.0.0.1:3099/api/v1}"
TIMESTAMP=$(date +%s)

echo "=========================================="
echo "  用户注册登录完整链路测试"
echo "=========================================="

# 步骤1: 微信授权登录
echo ""
echo "【步骤1】微信授权登录"
echo "----------------------------------------"
LOGIN_RESPONSE=$(curl -s -X POST "$BASE_URL/auth/wechat/login" \
  -H "Content-Type: application/json" \
  -d "{
    \"code\": \"test_code_user_${TIMESTAMP}\",
    \"userInfo\": {
      \"nickName\": \"测试用户_${TIMESTAMP}\",
      \"avatarUrl\": \"https://example.com/avatar.jpg\"
    }
  }")

echo "响应: $LOGIN_RESPONSE"
USER_TOKEN=$(echo $LOGIN_RESPONSE | grep -o '"token":"[^"]*"' | sed 's/"token":"//;s/"$//')
USER_ID=$(echo $LOGIN_RESPONSE | grep -o '"id":[0-9]*' | head -1 | sed 's/"id"://')
echo "用户Token: $USER_TOKEN"
echo "用户ID: $USER_ID"

# 检查点1: 验证用户数据入库
echo ""
echo "【检查点1】验证用户数据入库"
mysql -u root community_db -e "SELECT id, openid, nickname, avatar_url, created_at FROM users WHERE id = $USER_ID;"

# 步骤2: 绑定手机号
echo ""
echo "【步骤2】绑定手机号"
echo "----------------------------------------"
BIND_PHONE_RESPONSE=$(curl -s -X POST "$BASE_URL/user/bind-phone" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $USER_TOKEN" \
  -d '{"phone": "13800138000", "code": "123456"}')
echo "响应: $BIND_PHONE_RESPONSE"

# 检查点2: 验证手机号绑定
echo ""
echo "【检查点2】验证手机号绑定"
mysql -u root community_db -e "SELECT id, nickname, phone FROM users WHERE id = $USER_ID;"

# 步骤3: 绑定小区
echo ""
echo "【步骤3】绑定小区"
echo "----------------------------------------"
BIND_COMMUNITY_RESPONSE=$(curl -s -X POST "$BASE_URL/user/bind-community" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $USER_TOKEN" \
  -d '{"community_id": 1}')
echo "响应: $BIND_COMMUNITY_RESPONSE"

# 检查点3: 验证小区绑定
echo ""
echo "【检查点3】验证小区绑定"
mysql -u root community_db -e "SELECT u.id, u.nickname, u.community_id, c.name as community_name FROM users u LEFT JOIN communities c ON u.community_id = c.id WHERE u.id = $USER_ID;"

# 步骤4: 更新个人信息
echo ""
echo "【步骤4】更新个人信息"
echo "----------------------------------------"
UPDATE_RESPONSE=$(curl -s -X PUT "$BASE_URL/user/profile" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $USER_TOKEN" \
  -d '{"nickname": "更新后的昵称", "address": "上海市闵行区"}')
echo "响应: $UPDATE_RESPONSE"

# 检查点4: 验证个人信息更新
echo ""
echo "【检查点4】验证个人信息更新"
mysql -u root community_db -e "SELECT id, nickname, address FROM users WHERE id = $USER_ID;"

# 步骤5: 验证Token有效性
echo ""
echo "【步骤5】验证Token有效性"
echo "----------------------------------------"
PROFILE_RESPONSE=$(curl -s -X GET "$BASE_URL/user/profile" \
  -H "Authorization: Bearer $USER_TOKEN")
echo "用户信息: $PROFILE_RESPONSE"

# 步骤6: 查看个人中心
echo ""
echo "【步骤6】查看个人中心数据"
echo "----------------------------------------"
echo "查看余额: $(curl -s -X GET "$BASE_URL/user/profile" -H "Authorization: Bearer $USER_TOKEN")"

echo ""
echo "=========================================="
echo "  用户注册登录完整链路测试完成"
echo "=========================================="
```

### 1.2 检查点汇总

| 检查点 | 检查内容 | 检查SQL | 预期结果 |
|--------|----------|---------|----------|
| CP-01 | 用户数据入库 | `SELECT * FROM users WHERE id = ?` | 用户记录存在 |
| CP-02 | 手机号绑定 | `SELECT phone FROM users WHERE id = ?` | phone不为空 |
| CP-03 | 小区绑定 | `SELECT community_id FROM users WHERE id = ?` | community_id正确 |
| CP-04 | 个人信息更新 | `SELECT nickname, address FROM users WHERE id = ?` | 信息已更新 |
