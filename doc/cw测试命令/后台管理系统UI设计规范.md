# 后台管理系统UI设计规范

> **创建日期**: 2026-04-22  
> **适用范围**: 九州中台管理系统、服务商后台管理系统、商家后台管理系统

---

## 一、布局规范

### 1.1 整体布局结构

采用业界标准的**左右栏布局**（Lsidebar Layout）：

```
┌─────────────────────────────────────────────────────────────┐
│                        顶部栏 (Header)                       │
│  Logo  |  面包屑导航  |  用户信息 |  通知  |  设置         │
├────────────┬────────────────────────────────────────────────┤
│            │                                                │
│  左侧菜单   │              主体内容区域                      │
│  (Sidebar) │              (Main Content)                   │
│            │                                                │
│  - 菜单1   │  ┌────────────────────────────────────────┐  │
│  - 菜单2   │  │           页面标题 + 操作按钮            │  │
│  - 菜单3   │  ├────────────────────────────────────────┤  │
│    - 子菜单 │  │                                        │  │
│    - 子菜单 │  │            内容区域                     │  │
│  - 菜单4   │  │                                        │  │
│            │  │  - 表格/表单/卡片/图表                   │  │
│            │  │                                        │  │
│            │  └────────────────────────────────────────┘  │
│            │                                                │
└────────────┴────────────────────────────────────────────────┘
```

### 1.2 布局尺寸规范

| 区域 | 尺寸 | 说明 |
|------|------|------|
| 顶部栏高度 | 56px | 固定高度 |
| 左侧菜单宽度（展开） | 220px | 可配置 |
| 左侧菜单宽度（收起） | 64px | 图标模式 |
| 主体内容区内边距 | 24px | 页面级别 |
| 卡片内边距 | 20px | 组件级别 |
| 表格单元格内边距 | 12px 16px | 水平 16px，垂直 12px |

### 1.3 栅格系统

采用 **12列响应式栅格**，与主流UI组件库（Element Plus、Ant Design）保持一致：

| 断点 | 屏幕宽度 | 列数 |
|------|----------|------|
| xs | < 576px | 1 |
| sm | ≥ 576px | 2 |
| md | ≥ 768px | 3 |
| lg | ≥ 992px | 4 |
| xl | ≥ 1200px | 6 |
| xxl | ≥ 1400px | 8 或 12 |

## 二、组件规范

### 2.1 表格组件

**样式要求**：
- 表头背景色：`#F5F7FA`（浅灰色）
- 表头字体：14px，加粗，色值 `#303133`
- 表体字体：14px，常规，色值 `#606266`
- 行高：52px（包含表头），48px（数据行）
- 边框色：`#EBEEF5`
- 悬停背景色：`#F5F7FA`
- 斑马纹（可选）：奇数行 `#FAFBFC`

**交互要求**：
- 列排序：支持点击表头排序
- 列筛选：支持筛选下拉
- 行操作：操作按钮固定在最后一列
- 分页：底部固定，支持跳页

**列宽规范**：
- 最小列宽：80px
- 最大列宽：400px
- 常规列宽：120px - 200px

### 2.2 表单组件

**输入框规范**：
- 高度：40px
- 内边距：12px 15px
- 边框圆角：4px
- 边框色：`#DCDFE6`
- 聚焦边框色：`#409EFF`
- 错误边框色：`#F56C6C`

**标签规范**：
- 标签位置：上方（移动端）或左侧（PC端 ≥ 768px）
- 标签宽度（左侧）：120px
- 必填标识：红色星号 `*`

**间距规范**：
- 垂直表单项间距：18px
- 按钮与表单间距：24px

### 2.3 按钮规范

| 类型 | 背景色 | 文字色 | 边框 | 用途 |
|------|--------|--------|------|------|
| 主要按钮 | `#409EFF` | `#FFFFFF` | 无 | 提交、确认 |
| 次要按钮 | `#FFFFFF` | `#606266` | `#DCDFE6` | 取消、返回 |
| 成功按钮 | `#67C23A` | `#FFFFFF` | 无 | 通过、启用 |
| 危险按钮 | `#F56C6C` | `#FFFFFF` | 无 | 删除、拒绝 |
| 文字按钮 | 透明 | `#409EFF` | 无 | 更多操作 |

**按钮尺寸**：
- 大号：高度 40px，字体 16px
- 中号（默认）：高度 36px，字体 14px
- 小号：高度 28px，字体 12px

### 2.4 卡片组件

**样式规范**：
- 背景色：`#FFFFFF`
- 边框：1px solid `#EBEEF5`
- 圆角：8px
- 阴影：`0 2px 12px rgba(0, 0, 0, 0.05)`

**内边距**：20px

### 2.5 统计卡片

用于仪表盘数据展示：

```
┌─────────────────────────────────────┐
│  📊 今日订单                         │
│                                     │
│        1,234                        │  ← 数值：24px，加粗
│                                     │
│  ↑12% 较昨日                        │  ← 描述：14px
└─────────────────────────────────────┘
```

- 数值字体：24px，加粗，`#303133`
- 描述字体：14px，`#909399`
- 趋势箭头：绿色上涨 `↑`，红色下跌 `↓`

## 三、导航规范

### 3.1 顶部栏

**内容分布**（从左到右）：
1. Logo + 系统名称
2. 面包屑导航
3. 右侧：通知图标、用户头像+名称、设置

**高度**：56px

**背景色**：白色 `#FFFFFF`

**底边分割线**：`1px solid #EBEEF5`

### 3.2 左侧菜单

**菜单项样式**：
- 菜单高度：48px
- 菜单内边距：0 16px
- 图标尺寸：18px
- 文字大小：14px

**菜单层级**：
- 一级菜单：无缩进
- 二级菜单：缩进 16px
- 三级菜单：缩进 32px

**选中状态**：
- 背景色：`#409EFF15`（主题色10%透明度）
- 文字色：`#409EFF`
- 左边框：3px solid `#409EFF`

**展开/收起**：
- 支持点击展开/收起
- 展开宽度：220px
- 收起宽度：64px（仅显示图标）

### 3.3 面包屑

**分隔符**：`/` 或 `>`

**样式**：
- 字体：14px
- 颜色（未选中）：`#909399`
- 颜色（当前）：`#303133`

## 五、间距规范

### 5.1 间距系统

采用 **4px 基准倍数**：

| 名称 | 数值 | 用途 |
|------|------|------|
| xs | 4px | 紧凑元素 |
| sm | 8px | 组件内部 |
| md | 16px | 组件间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 区块间距 |
| xxl | 48px | 页面间距 |

### 5.2 常用间距组合

```
页面标题 ↓ 24px ↓ 搜索区域 ↓ 16px ↓ 表格/内容
```

```
卡片标题 ↓ 16px ↓ 卡片内容
```

```
表单标签 ↓ 0 (左侧) |  表单项 ↓ 18px ↓ 表单项
```

| 辅助文字 | 12px | 18px | 400 |

## 七、响应式断点

| 断点 | 屏幕宽度 | 布局变化 |
|------|----------|----------|
| xs | < 576px | 单列布局，底部导航 |
| sm | ≥ 576px | 双列布局 |
| md | ≥ 768px | 左侧菜单展开 |
| lg | ≥ 992px | 标准布局 |
| xl | ≥ 1200px | 宽屏布局 |
| xxl | ≥ 1400px | 大屏布局，可显示更多列 |

## 八、可访问性规范

### 8.1 颜色对比度

- 文本与背景对比度 ≥ 4.5:1（普通文本）
- 文本与背景对比度 ≥ 3:1（大文本 ≥ 18px 或 粗体 ≥ 14px）

### 8.2 交互反馈

- 所有可点击元素具有 hover、focus、active 状态
- 焦点元素有可见的焦点轮廓
- 加载状态有 loading 指示

### 8.3 键盘导航

- 支持 Tab 键导航
- 支持 Enter/Space 键确认
- 支持 Escape 键取消/关闭

---

## 九、性能优化

### 9.1 懒加载

- 路由懒加载
- 图片懒加载
- 表格虚拟滚动（大数据量 > 1000行）

### 9.2 缓存策略

- 列表页缓存查询条件
- 表单数据暂存（防止误刷新丢失）

### 9.3 代码分割

- 第三方库独立打包
- 公共组件独立打包

## 十、实施建议

### 10.1 UI组件库选型

推荐使用以下成熟的B端UI组件库：

| 组件库 | 特点 | 适用场景 |
|--------|------|----------|
| Element Plus | Vue3生态，文档完善 | 通用后台 |
| Ant Design Vue | 企业级，功能丰富 | 复杂业务后台 |
| Naive UI | Vue3，TypeScript友好 | 现代后台 |

### 10.2 图标资源

推荐使用：
- **Iconify**：开源图标库，40000+图标
- **阿里巴巴图标库**：免费商用的图标库

### 10.3 图表库

推荐使用：
- **ECharts**：百度开源，功能强大
- **Chart.js**：轻量级，简单易用
- **AntV**：蚂蚁金服，专业数据可视化
