# 自动化测试脚本使用说明

## 一、测试脚本列表

| 脚本名称 | 用途 | 执行方式 |
|----------|------|----------|
| e2e-cw-fullflow.js | 全流程E2E测试 | npm run test:e2e |
| test-api-auth.sh | 认证模块API测试 | bash test-api-auth.sh |
| test-api-home.sh | 首页模块API测试 | bash test-api-home.sh |
| test-api-service.sh | 到家服务API测试 | bash test-api-service.sh |
| test-api-market.sh | 本地集市API测试 | bash test-api-market.sh |
| test-api-assist.sh | 邻里帮帮API测试 | bash test-api-assist.sh |
| test-admin.sh | 管理后台API测试 | bash test-admin.sh |

## 二、环境准备

### 2.1 安装依赖

```bash
cd /root/community-backend/backend
npm install
```

### 2.2 配置环境变量

```bash
# 复制环境配置
cp .env.example .env

# 编辑配置
vi .env
```

### 2.3 启动服务

```bash
# 开发模式
npm run dev

# 生产模式
npm start
```

## 三、执行测试

### 3.1 执行全流程测试

```bash
npm run test:e2e
```

### 3.2 执行单个模块测试

```bash
# 认证模块
bash scripts/test-api-auth.sh

# 首页模块
bash scripts/test-api-home.sh

# 到家服务
bash scripts/test-api-service.sh

# 本地集市
bash scripts/test-api-market.sh

# 邻里帮帮
bash scripts/test-api-assist.sh

# 管理后台
bash scripts/test-admin.sh
```

## 四、测试报告

测试报告生成在 `doc/cw测试结果/` 目录下，文件名格式：

```
后端首页全流程回环测试报告_<时间戳>.md
```

## 五、常见问题

### 5.1 端口被占用

```bash
# 查看端口占用
lsof -i:3099

# 杀掉进程
kill -9 <PID>
```

### 5.2 数据库连接失败

```bash
# 检查MySQL服务
systemctl status mysql

# 重启MySQL
systemctl restart mysql
```

### 5.3 测试数据残留

```bash
# 清理测试数据
mysql -u root -p community_db < scripts/cleanup-test-data.sql
```
