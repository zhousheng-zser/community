## 四、接口参数格式说明

### 4.1 服务订单创建接口
```json
{
  "service_id": 1,
  "worker_id": 1,
  "community_id": 1,
  "address_snapshot": {
    "contact": "张三",
    "contact_phone": "13800138000",
    "detail": "1号楼101室"
  },
  "appointment_time": "2026-04-23 10:00:00",
  "qty": 1
}
```

### 4.2 邻里帮帮创建接口
```json
{
  "assist_type": "take",
  "origin_address_snapshot": {
    "contact": "李四",
    "contact_phone": "13900139000",
    "detail": "菜鸟驿站"
  },
  "destination_address_snapshot": {
    "contact": "张三",
    "contact_phone": "13800138000",
    "detail": "1号楼101室"
  },
  "community_id": 1,
  "amount": 10.00
}
```

**有效的 assist_type 值**:
- `take`: 代取快递
- `child`: 接送孩子
- `escort`: 陪诊陪护
- `trash`: 代扔垃圾
- `pet`: 宠物代办
