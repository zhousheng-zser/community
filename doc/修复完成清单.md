### 4. 聊天功能模块 ✅

#### 新增文件：`api/chat-order.js`
- 订单相关聊天 API 接口
- 支持订单聊天列表获取
- 支持订单聊天消息发送
- 订单完成后自动建立聊天群

**后端需对接接口**：
- `GET /chats/movie/order/:orderId` - 获取聊天列表
- `POST /chats/movie/order/:orderId` - 发送消息
- `POST /chats/movie/order/:orderId/get-messages` - 获取消息历史

---

### 5. 订单状态统一管理 ✅

#### 新增文件：`utils/orderStatus.js`
统一所有订单类型的状态定义：

| 订单类型 | 状态枚举 |
|---------|---------|
| 服务订单 | pending_pay, pending_worker_accept, dispatched, in_service, pending_user_confirm, completed, cancelled, refunded |
| 邻里帮帮 | pending_pay, paid_pending_dispatch, dispatched, in_service, completed, confirmed, cancelled |
| 集市订单 | pending_payment, pending_accept, pending_service, pending_receipt, completed, cancelled, refunded |

**提供的工具函数**：
- `getStatusText(status, type)` - 获取状态显示文本
- `getStatusShort(statusText)` - 获取状态简写
