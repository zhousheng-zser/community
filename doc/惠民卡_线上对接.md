# 惠民卡与线上社区 API 对接说明

## 1. 线上服务实际行为（HTTP 探测结论）

对 `http://8.140.204.254:3000` 探测可知：

| 路径 | 结果 |
|------|------|
| `GET /` | `200`，`Welcome to Community Mini-Program API!` |
| `GET /api/v1/posts/` | `200`，帖子列表（主业务在社区一体化 API） |
| `GET /api/v1/core/services/1` | `200`，服务详情 |
| `GET /api/v1/market/shops` | `200`，集市店铺 |
| `GET /api/v1/jd/benefit/goods` | **404**，HTML `Cannot GET ...`（默认 Express 404 页） |

结论：**当前 3000 端口进程是「社区主 API」**，**未注册**京东/拼多多惠民卡路由。  
本仓库里的 `backend/src/app.js` 是**另一套**仅含惠民卡 + 管理登录的精简应用；**发帖 / core / market 等主业务源码不在本仓库**，因此不能只替换 3000 端口进程而不丢业务。

---

## 2. 推荐方案 A：独立进程 + Nginx 反代（不改主服务代码）

1. 在服务器上部署本仓库 **`backend/`**（`npm install --omit=dev`、配置 `.env` 连同一台 MySQL）。
2. 用 **PM2** 单独启动惠民卡服务（默认 **3001** 端口）：

   ```bash
   cd /path/to/community/backend
   pm2 start ecosystem.benefit.pm2.cjs
   pm2 save
   ```

3. 在 **Nginx**（或前面入口）增加反代：把  
   `/api/v1/jd`、`/api/v1/pdd`、`/api/v1/benefit`  
   转到 `http://127.0.0.1:3001`（**同路径**）。片段见 **`deploy/nginx-benefit-proxy-snippet.conf`**。
4. 小程序仍访问 `http://8.140.204.254:3000`（或你的域名）；由 Nginx 拆分到主 API 与惠民卡服务。

验证：

- `GET http://127.0.0.1:3001/api/v1/meta` → JSON 且 `benefit: true`
- 经 Nginx：`GET .../api/v1/jd/benefit/goods?scene=benefit_card` → `errno:0` 且 `data.list` 有数据（需已灌库）

---

## 3. 方案 B：与主服务同进程（有主服务源码时）

若你持有主 `app.js` 且可改部署：

1. 将本仓库 **`backend/`** 整目录放到服务器（例如 `/root/community-benefit-backend`）。
2. 在该目录执行 `npm install --omit=dev`。
3. 在主服务 **创建 Express `app` 之后、`listen` 之前**增加：

   ```javascript
   const path = require('path');
   const mountBenefit = require(path.join(
     __dirname,
     'community-benefit-backend',
     'src',
     'mountBenefitAlliance'
   ));
   mountBenefit(app);
   ```

   路径按实际目录调整；**工作目录不影响**，`mountBenefitAlliance.js` 内部使用相对本文件的 `require`。

4. 主进程需能连 MySQL（与本仓库 `backend/.env` 一致），并执行建表 + `seed:benefit`（或 SQL）。

本仓库中 **`backend/src/mountBenefitAlliance.js`** 即为可复用的挂载入口；**`backend/src/app.js`** 通过调用该函数注册相同路由。

## 5. 勿混淆

- 仅替换线上 `node` 为**本仓库 `backend/src/index.js` 且仍监听 3000**：会**失去** posts/core/market 等主接口，除非主业务已合并进同一进程（当前仓库无该合并代码）。
- `Cannot GET /api/v1/jd/benefit/goods` 的 **HTML** 说明响应来自**未注册该路由的 Express**，不是本仓库 `app.js` 的 JSON 404。
