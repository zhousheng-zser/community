## 二、服务订单模块问题修复

### 2.1 问题分析

**问题**: 用户创建服务订单后，"我的"页面 (`pages/service-orders-my/service-orders-my.js`) 无法显示该订单

**根本原因**:
1. 页面只在 `onShow` 时调用 `load()` 加载一次数据
2. 没有监听后端订单状态变更的推送机制
3. 下单成功后需要手动刷新或切换 Tab 才能看到

### 2.2 修复方案

#### 修复文件：`pages/service-orders-my/service-orders-my.js`

```javascript

  // 保存上页参数以便返回后继续展示
```

```javascript
  const userFlag = this.data.userFlag;

  });
  
  return list;
}
```

## 三、邻里帮帮模块修复

### 3.1 问题分析

**问题**: 
1. `pages/order-publish/order-publish.js` 中下单逻辑复杂，存在两套代码路径
2. 支付流程依赖 mock，正常下单会失败
3. 订单同步到"邻里帮帮"订单列表的机制不完整

### 3.2 修复方案

#### 修复文件：`pages/order-publish/order-publish.js`

**优化下单逻辑**：

```javascript
// 简化发布流程：只保留一套清晰的主逻辑
async submitPublish() {
  const { form, activeCategory, agreed, submitting } = this.data;
  if (submitting || !form.address || !form.content || !agreed) {
    return wx.showToast({ title: '请完善信息', icon: 'none' });
  }
  
  this.setData({ submitting: true });
  
  try {
    // 1. 上传图片
    const imageUrls = [];
    for (const filePath of form.images) {
      const result = await util.uploadFile('upload', filePath, 'file', { type: 'order' });
      if (result.url) imageUrls.push(result.url);
    }
    
    // 2. 创建订单
    const rewardAmount = form.price ? parseFloat(form.price) : null;
    const orderRes = await util.post('neighbor-assist/orders', {
      assist_type: activeCategory,
      content: form.content,
      remark: form.content,
      community_id: 1,
      origin_address_snapshot: { address: form.address, detail: form.address },
      destination_address_snapshot: { address: form.address, detail: form.address },
      appointment_time: form.time || null,
      reward_amount: rewardAmount
    });
    
    const orderId = orderRes.id || orderRes.order_id;
    
    // 3. 模拟支付（开发联调用）
    if (orderId) {
      try {
        await util.post(`neighbor-assist/orders/${orderId}/pay`);
      } catch (payErr) {
        console.warn('支付接口未就绪，订单已创建:', orderId);
      }
    }
    
    // 4. 同步到社区帖子（异步）
    syncToCommunityPost(form.content, activeCategory, form.address, rewardAmount, imageUrls);
    
    wx.showToast({ title: '发布成功', icon: 'success' });
    this.resetForm();
    
  } catch (err) {
    console.error('发布失败:', err);
    wx.showToast({ title: '发布失败，请重试', icon: 'none' });
    this.setData({ submitting: false });
  }
}
```

## 四、聊天功能集成

### 4.1 问题分析

当前系统下单后，服务商和用户可以分别看到订单，但缺乏实时聊天功能。

### 4.2 修复方案

#### 新增文件：`pages/chat-order/chat-order.js`

```javascript
const util = require('../../utils/util.js');
const api = require('../../api/index.js');

Page({
  data: {
    orderId: '',
    messages: [],
    inputText: ''
  },
  
  async onLoad(options) {
    this.setData({ orderId: options.id });
    await this.loadMessages();
    
    // 2.5 分钟轮询消息（临时方案，后续用 WebSocket）
    this.timer = setInterval(() => {
      this.loadMessages().then(() => {
        this.setData({ messages: this.data.newMessages });
      });
    }, 150000);
  },
  
  async loadMessages() {
    try {
      const res = await api.chat.getOrderMessages(this.data.orderId);
      this.setData({ messages: res.list || res.data });
    } catch (e) {
      console.log('加载聊天消息失败', e);
    }
  },
  
  async sendMessage() {
    if (!this.data.inputText.trim()) return;
    
    const msg = { role: 'buyer', content: this.data.inputText };
    this.setData({ messages: [...this.data.messages, msg], inputText: '' });
    
    try {
      await api.chat.sendOrderMessage(this.data.orderId, msg);
    } catch (e) {
      // 失败时保留本地消息，等待网络恢复
    }
  },
  
  inputHandler(e) {
    this.setData({ inputText: e.detail.value });
  },
  
  onUnload() {
    if (this.timer) clearInterval(this.timer);
  }
});
```

#### api/chat.js 补充接口


### 9.1 相关 API 路径汇总

```
服务订单 (user):
  GET  /api/v1/service-orders/my              # 我的订单
  GET  /api/v1/service-orders/:id             # 订单详情
  POST /api/v1/service-orders/:id/pay         # 支付
  POST /api/v1/service-orders/:id/confirm-complete  # 确认完成

服务订单 (worker):
  GET  /api/v1/worker/service-orders          # 技工订单列表
  GET  /api/v1/worker/service-orders/:id      # 订单详情
  POST /api/v1/worker/service-orders/:id/accept      # 接单
  POST /api/v1/worker/service-orders/:id/complete    # 完成
  POST /api/v1/worker/service-orders/:id/check-in    # 打卡

邻里帮帮 (publisher):
  POST /api/v1/neighbor-assist/orders         # 创建订单
  GET  /api/v1/neighbor-assist/orders/my?role=publisher

邻里帮帮 (helper):
  GET  /api/v1/neighbor-assist/orders/my?role=helper

集市购物:
  GET  /api/v1/market/orders                  # 我的订单
  POST /api/v1/market/orders/:orderNo/cancel  # 取消
  POST /api/v1/market/orders/:orderNo/pay     # 支付
```
