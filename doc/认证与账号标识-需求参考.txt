【一】注册账号
--------------------------------------------------------------------------------

  POST /auth/register

  必填 body：
    phone         手机号
    sms_code      短信验证码（开发环境固定 024680；兼容旧字段 code）
    password      登录密码
    wx_code       微信小程序 wx.login() 返回的 code（用于绑定当前微信）

  可选：nickname, avatar_url, address, lat, lng

  规则：
    - 必须同时完成：手机 + 验证码 + 密码 + 绑定当前微信（openid）
    - 手机号已被占用 → HTTP 409，msg: 「该手机号已被绑定，请更换手机号或直接登录」
    - 当前微信已注册 → HTTP 409，msg: 「当前微信已注册，请直接微信登录」
    - 验证码错误 → HTTP 400

  成功响应示例：
    {
      "code": 0,
      "msg": "注册成功",
      "token": "<JWT>",
      "user": {
        "id": "313949477532602368",
        "phone": "19912345678",
        "nickname": "用户5678",
        "avatar_url": "",
        "openid": "mock_openid_xxx"
      },
      "data": { "id": "...", "phone": "...", "lat": null, "lng": null }
    }

  辅助：
    POST /auth/sms/send       body: { phone, type }  type: register|login|forget_password
    POST /auth/password_reset body: { phone, code, new_password }


【二】登录账号
--------------------------------------------------------------------------------

  （1）微信登录  POST /auth/login
    body: { code }   // wx.login 的 code，不是短信验证码
    可选: nickname, avatar_url

    - 该 openid 已注册 → 200，返回 token + user
    - 未注册 → 404，msg: 「该微信尚未注册，请先完成手机号注册并绑定微信」
    - 不再自动创建用户

  （2）手机号 + 验证码  POST /auth/login_sms   【新增】
    body: { phone, code }   // 验证码默认 024680
    - 不要求带微信 code；登录的是手机号账号，与当前微信是否绑定无关
    - 未注册 → 401

  （3）手机号 + 密码  POST /auth/login_password
    body: { phone, password }
    - 同上，与当前微信无关

  成功响应（三种登录类似）：
    {
      "code": 0,
      "msg": "登录成功",
      "token": "<JWT>",
      "user": { "id": "3139...", "phone": "...", "nickname": "...", "avatar_url": "...", "openid": "..." },
      "data": { "token": "<JWT>" }
    }

  兼容：GET /auth/wx/getkey/:code  → 等同 POST /auth/login

  登出：POST /auth/logout  Header: Authorization: Bearer <token>

2) 运营后台（未改）

  POST /auth/admin/login
    body: { username, password }
    返回 data.token（JWT 含 admin:true，与 C 端用户 token 分离）


【三】数据库唯一标识符（已实现）
--------------------------------------------------------------------------------

  Users.id
    - 类型：BIGINT，雪花算法生成（非自增、非 UUID）
    - 新建用户由服务端 beforeValidate 自动分配
    - 全库 user_id / invited_by 等外键已迁移为 BIGINT 雪花 id
    - 历史重复手机号：保留最早账号原号；其余账号分配以 1 开头的 11 位新手机号
    - 旧 int 自增 id 已删除；对照表 user_id_migration（old_id → new_id）保留在库中供核对

  业务标识：
    - 系统内主键 / JWT 中的 id：Users.id（字符串形式的雪花 id，避免 JS 精度问题）
    - 微信：openid（注册时绑定）


【四】登录凭证（给前端）
--------------------------------------------------------------------------------

  登录/注册成功后字段 token 为 JWT，后续请求：

    Authorization: Bearer <token>

  JWT payload 含：id（字符串）, openid, token_version
  用户 id 请一律按字符串处理，勿 parseInt。

【给前端同事】联调说明（语料，可直接转发）
================================================================================

1. 注册流程（必须改）
   - 页面：手机号 + 获取验证码 + 密码 + 用户协议。
   - 提交前必须先 wx.login() 拿到 code，注册接口传 wx_code（不要和短信验证码共用字段名）。
   - 短信验证码字段名：sms_code（值开发环境填 024680）；若仍传 code 也可兼容。
   - 409 时按 msg 提示：换手机号或去登录；微信已注册则走微信登录。

2. 登录三种方式（按场景选一种）
   A. 微信一键登录：wx.login() → POST /auth/login { code }
      - 404 表示未注册，跳转注册页并带上刚拿到的 code 用于注册绑微信。
   B. 手机号验证码登录：POST /auth/login_sms { phone, code }，无需 wx code。
   C. 手机号密码登录：POST /auth/login_password { phone, password }，无需 wx code。

3. Token
   - 注册/登录成功保存 res.token（或 res.data.token，以实际返回为准，当前两种字段都有）。
   - 之后所有需登录接口加 Header：Authorization: Bearer ${token}
   - 用户 id 使用 res.user.id，类型为字符串雪花 id，不要当 Number 用。

4. 短信
   - 发码：POST /auth/sms/send { phone, type: "register"|"login"|"forget_password" }
   - 开发环境验证码固定 024680。

5. 运营后台
   - 仍用 POST /auth/admin/login，与小程序用户 token 不要混用。

6. 破坏性变更注意
   - 老用户 id 已从 1、2、3… 变为雪花 id；本地缓存的 userId、订单关联展示需清缓存或重新登录。
   - 微信登录不再静默注册，新用户必须走注册接口。
