# 第五阶段：测试、域名及发版部署流程

距离这个完美的社区带货大作能在用户的微信搜索栏出现，我们只差临门一脚。这是整个战役收尾的地方：

## 1. 测试及连通性攻坚战

这是一趟寻找 Bug 并干掉它们的旅程。要重点测以下极易爆炸的系统边缘：

- **大文件验证**：选一个长长的手机视频作为“用户”上传，测试前后端传输分期、云对象上传进度条卡不卡死以及显示有无报错。
- **高并发抢购测试**：对爆款秒杀商品利用 JMeter 进行高频率点击压力测试，看后端的 MySQL 库存是否出现“超卖”现象。必须采用**事务隔离**或者**Redis分布式锁**应对。
- **沙盒资金流动检测**：在不花真钱的前提下，在您的微信开发者工具的支付“模拟沙盒模式”里完整演示一套：商品挑选 -> 模拟结账 -> 余额新增佣金额度 -> 模拟提现，观察每一条流水账是否吻对库。

## 2. 域名、证书备案及后端挂载

**微信的死要求：所有与小程序的通信接口、素材地址，都必须全套采用 `HTTPS` 安全协议访问，否则直接拦截。**

- **域名备案**：买一个您喜爱的域名（如 `your-store.com`）到工信部完成 ICP 备案审核（通常约 10-20 天，需提早动手）。
- **SSL 加密配置**：给您的域名申请并安装权威的 SSL 证书。在 Nginx 或 Node 服务器前端配好 `https`。
- **部署上线**：将后端的 MySQL 与 Node.js 镜像投到线上（可上云服务器，如腾讯云轻量级应用服务器 CVM），配合 `PM2` 与 `Docker` 保持服务长生不死。
- **白名单录入**：到「微信公众平台 -> 小程序 -> 服务器域名配置」里，将这个配置好了的 `https://your-store.com` 和您买好的对象存储域名填入 Request 连网白名单池。

## 3. 过审与全量发版发布

- 在所有的前端细节（真机预览无误）打磨光亮并接上真实线上云后，点击右上角开发者工具的“上传”。
- **提交流程**：前往公众平台管理端找到所上传之版本，确认资质类目合规并填写更新日记后点击 **提交微信团队人工审核**。
- **过审后**：一旦微信放行，恭喜您，只需要最后点击“全量发布”，您的结晶便正式活在了微信 10 亿用户的流量池里。
