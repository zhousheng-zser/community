## 四、前后端联调

### 4.1 联调流程

```
前端 (小程序)                    后端 (Node.js)
      |                               |
      |--- wx.login() → code -------->|
      |                               |
      |--- POST /auth/login {code} -->|
      |<-- {token, user} -------------|
      |                               |
      |--- 请求 (Bearer token) ------>|
      |<-- {success, data} -----------|
```

### 4.2 前端请求封装

前端统一通过 `utils/util.js` 的 `request()` 方法发起请求:

```javascript
// utils/util.js 核心逻辑
const request = (method, url, data) => {
  const finalUrl = config.baseUrl + url;
  const token = wx.getStorageSync('token');
  // wx.request 自动附加 Authorization 头
};

// 简化为 post/get
const post = (url, data) => request('POST', url, data);
const get = (url, data) => request('GET', url, data);
```

各模块 API 文件（`api/*.js`）在此基础上封装具体接口:

```javascript
// api/market.js 示例
const { post, get } = require('../utils/util.js');

const getGoodsDetail = (id) => get('/market/goods/' + id);
const createOrder = (data) => post('/market/order/create', data);
```

页面中调用:

```javascript
// pages/xxx/xxx.js
const api = require('../../api/index.js');

// 使用
const res = await api.market.getGoodsDetail(1);
```

## 七、常见问题

### 7.1 Token 过期

- JWT token 有效期 7 天
- 过期后调用登录接口重新获取
- 前端 `app.js` 中应处理 401 响应并引导重新登录

### 7.2 图片资源

- 服务器上传图片路径: `/uploads/`
- 前端通过 `utils/util.js` 的 `imgUrl()` 函数处理图片路径转换
- 本地占位图在 `img/` 目录，上传目录映射在 `config.uploadsImageSubdirs` 中配置

### 7.3 分包加载

- 主包 + 5 个分包（worker/merchant/market/service-provider/rider）
- 分包页面通过 `wx.switchTab` 或 `wx.navigateTo` 跳转
- 跨分包跳转需使用完整页面路径，如 `package-worker/pages/worker-home/worker-home`

### 7.4 HTTPS 与合法域名

- 开发者工具里 `project.config.json` 的 `urlCheck: false` 仅影响工具内校验；**真机预览、体验版、正式版**仍会校验「request / uploadFile / downloadFile」合法域名。
- 更换 API 域名后，必须在[微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → 开发设置 → **服务器域名** 中把 `https://120.27.239.244:3001` 加入 **request 合法域名**（图片若走同域，还需 **downloadFile** 等）。
- 若未配置，真机上 `wx.request` 会失败，界面常表现为 Toast「网络错误」；控制台 `errMsg` 多为 `request:fail url not in domain list`。`utils/util.js` 已对该类失败提示为「域名未在公众平台配置」。
- 证书需有效且链完整；域名须与证书 CN/SAN 一致。
