# 第三阶段：核心数据服务（只读）

## 1. 当前完成进度
本阶段主要处理了应用首页以及分类页所需展示的核心数据信息。通过预先写入一些测试（种子）数据，帮助前端即使没有发帖也能看到完整的页面效果。

- [x] 创建 `Categories`（分类） 表结构及模型。
- [x] 创建 `Banners`（轮播图） 表结构及模型。
- [x] 创建 `Services`（服务/商品） 表结构及模型，并在 Sequelize 中配置它与 Category 表的级联关系。
- [x] 编写 `init-core-data` 种子（Seed）脚本，并往数据库成功插入了测试用的轮播图、三个分类（家政、维修、二手交易）以及几项测试服务数据。
- [x] 实现了核心数据查询的只读接口（这部分接口**无需携带 Token，游客可直接访问**）：
  - `GET /api/v1/core/banners`：获取首页轮播图。
  - `GET /api/v1/core/categories`：获取全部分类标签。
  - `GET /api/v1/core/services/hot`：获取最多前 6 个热门推荐服务（按销量 `sales_count` 倒序）。
  - `GET /api/v1/core/categories/:categoryId/services`：根据分类 ID 获取该分类下的分页服务列表。
  - `GET /api/v1/core/services/:id`：获取单个服务的完整详情。
- [x] 将对应的 API 路由 `coreDataRoutes` 挂载到了为主服务。

## 2. API 接口指引 (测试或前端联调时使用)

*注意：以下接口都不需要在 Headers 里带 Authorization Token。*

### 2.1 获取首页轮播图
**请求:** `GET http://localhost:3000/api/v1/core/banners`

### 2.2 获取全部分类
**请求:** `GET http://localhost:3000/api/v1/core/categories`

### 2.3 获取首页热门推荐服务
**请求:** `GET http://localhost:3000/api/v1/core/services/hot`

### 2.4 查看某个分类下的商品列表
**请求:** `GET http://localhost:3000/api/v1/core/categories/1/services?page=1&limit=10`
*(其中 URL 路径里的 `1` 代表 Category ID，家政服务分类)*

### 2.5 获取服务详情
**请求:** `GET http://localhost:3000/api/v1/core/services/1`
