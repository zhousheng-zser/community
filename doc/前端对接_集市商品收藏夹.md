# 集市商品收藏夹 — 前端对接说明

## 概述

- 每个登录用户在服务端对应**一个逻辑上的「收藏夹」**：数据上表现为该用户下多条收藏记录，**同一商品仅可收藏一次**（唯一键：`user_id` + `goods_id`）。
- **商品唯一标识**：使用表 `market_goods` 的主键 **`id`**，与店铺商品列表接口返回的每条商品的 **`id`** 字段一致。
  - 列表来源示例：`GET /api/v1/market/shops/{shopId}/goods`
  - 前端在列表项里取 `item.id`，作为下文接口中的 **`goods_id`** 即可。

> 说明：`goods_no` 为业务货号（全局唯一），本期接口统一用数字主键 **`goods_id`（= `market_goods.id`）**，与现有购物车 `goods_id` 含义一致，便于前后端对齐。

## 环境与前缀

- 生产示例基址：`https://jshsp1.eds-tech.cn`
- 集市 API 前缀：`/api/v1/market`
- 全文路径形如：`https://jshsp1.eds-tech.cn/api/v1/market/favorites`

## 认证

除调试环境外，均需登录态：

```http
Authorization: Bearer <JWT>
```

未携带或 token 无效时返回 `401`，业务错误时响应体一般为 `{ code, msg, data }`；成功时常见 `code === 0`。

## 接口列表

### 1. 查询收藏状态（批量）

用于商品列表、详情页批量判断是否已收藏（星标）。

```http
GET /api/v1/market/favorites/status?goods_ids=101,102,103
```

| 查询参数 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| goods_ids | string | 是 | 逗号或空格分隔的 `goods_id`，最多处理约 200 个去重后的 id |

**响应示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "favorited": {
      "101": true,
      "102": false,
      "103": true
    }
  }
}
```

---

### 2. 收藏列表（分页）

```http
GET /api/v1/market/favorites?page=1&page_size=20&shop_id=142
```

| 查询参数 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| page | number | 否 | 默认 1 |
| page_size | number | 否 | 默认 20，最大 100 |
| shop_id | number | 否 | 若传则只返回该店铺下的收藏 |

**响应说明**

- `data.list[]` 每一项包含：
  - `id`：收藏记录主键（一般前端用 `goods_id` 即可取消收藏）
  - `goods_id`、`shop_id`
  - `created_at`、`updated_at`
  - `good`：当前 `market_goods` 行 JSON（含 `status` 等；下架商品仍会展示，便于做「已下架」提示）
  - `shop`：店铺摘要（`id`, `name`, `logo_url`, `cover_url`, `is_active`, `category`）

---

### 3. 添加收藏

```http
POST /api/v1/market/favorites
Content-Type: application/json

{
  "goods_id": 12345
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| goods_id | number | 是 | 即店铺商品列表中的 `id` |
| shop_id | number | 否 | 若传，必须与该商品真实 `shop_id` 一致，否则 `400` |

**行为**

- 商品不存在：`404`，`code: 20011`（与购物车等业务对齐文案）
- 已收藏过：仍返回 `200`，`data.created === false`，不报错（幂等）

**响应示例**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "id": 8,
    "goods_id": 12345,
    "shop_id": 142,
    "created": true,
    "created_at": "2026-05-10T12:00:00.000Z",
    "updated_at": "2026-05-10T12:00:00.000Z"
  }
}
```

---

### 4. 取消收藏

```http
DELETE /api/v1/market/favorites/{goodsId}
```

路径参数 **`goodsId`** 为 **`goods_id`（商品主键）**，不是收藏记录 `id`。

- 未收藏该商品：`404`，`msg: 未收藏该商品`

---

## 与店铺商品列表的对应关系

1. 请求：`GET /api/v1/market/shops/142/goods?page=1&page_size=50`
2. 取返回 `data.list[].id` → 作为 **`goods_id`**
3. 收藏：`POST /api/v1/market/favorites`，body `{ "goods_id": <id> }`
4. 取消：`DELETE /api/v1/market/favorites/<id>`

## 数据库（供联调对照）

| 表名 | 作用 |
|------|------|
| `market_favorite_items` | 用户收藏行：`user_id`, `goods_id`, `shop_id` |
| `market_goods` | 商品：`id` 即接口中的 `goods_id` |
