# 第三方配送接入说明（美团 / 饿了么蜂鸟）

## 适用范围

仅 **本地集市订单**（`market_orders`，`delivery_mode=express`）。

## 环境变量

```bash
# 关闭模拟、启用真实 API（须同时配置对应平台密钥）
DELIVERY_MOCK=0

# 回调公网根地址（蜂鸟 notify_url 自动拼接）
DELIVERY_WEBHOOK_BASE=https://jshsp1.eds-tech.cn

# 美团配送开放平台 https://peisong.meituan.com
MEITUAN_APP_KEY=
MEITUAN_SECRET=
MEITUAN_SHOP_ID=          # 开放平台门店 ID，联调可用 test_0001
MEITUAN_SERVICE_CODE=4012 # 及时达，按合同调整
MEITUAN_PAY_TYPE=0        # 0账期 1余额
MEITUAN_ORDER_SOURCE=202  # 商家小程序-微信
# MEITUAN_API_BASE=https://peisongopen.meituan.com/api

# 饿了么蜂鸟即配 https://open-anubis.ele.me
ELEME_APP_KEY=            # app_id
ELEME_SECRET=             # secret_key
ELEME_CHAIN_STORE_CODE=   # 蜂鸟门店编码（与 ELEME_SHOP_ID 二选一）
# ELEME_NOTIFY_URL=       # 不填则用 DELIVERY_WEBHOOK_BASE + /market/delivery/webhook/eleme
# ELEME_API_BASE=https://open-anubis.ele.me/anubis-webapi
```

未配置密钥或 `DELIVERY_MOCK` 未设为 `0` 时，仍走本地 **MOCK 轨迹**（约 2 分钟模拟全流程）。

## 坐标要求

| 字段 | 来源 |
|------|------|
| 收货经纬度 | 用户地址地图选点 → 创单写入 `market_orders.receiver_latitude/longitude` |
| 门店经纬度 | `merchant_shops.latitude/longitude`（商家资料） |

执行 `backend/sql/0435_market_orders_receiver_geo.sql` 增加收货坐标列。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/market/merchant/orders/:orderNo/delivery/options` | 可选配送方式 |
| POST | `/market/merchant/orders/:orderNo/delivery/launch` | `{ provider: 'meituan'\|'eleme'\|'self' }` |
| GET | `/market/merchant/orders/:orderNo/delivery/track` | 商家查进度 |
| GET | `/market/orders/:orderNo/delivery/track` | 买家查进度 |
| POST | `/market/delivery/webhook/meituan` | 美团状态回调（验签 SHA1） |
| POST | `/market/delivery/webhook/eleme` | 蜂鸟状态回调 |

## 实现文件

- `backend/src/services/marketDelivery.service.js` — 业务编排
- `backend/src/services/delivery/meituanPeisong.client.js` — 美团 `order/createByShop`、`order/status/query`
- `backend/src/services/delivery/fengniaoDelivery.client.js` — 蜂鸟 token、`/v2/order`、`/v2/order/query`

## 状态映射

**美团** `status`：0→等待接单，20→已接单，30→已取货，50→已送达，99→已取消

**蜂鸟** `order_status`：1→等待，2→已接单，3→到店，4→配送中，5→已送达，6/7→已取消

## 上线检查

1. 开放平台配置回调 URL（美团须 80/8080 端口或按商务约定）
2. 254 执行 SQL 0433、0435，配置 `.env` 后 `pm2 restart community-benefit-api`
3. 小程序下单时选择 **带地图定位** 的收货地址
4. 商家店铺资料补全经纬度
