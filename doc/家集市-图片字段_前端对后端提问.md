# 本地集市图片展示异常 — 前端对后端排查说明（可转发）

> 口吻：前端联调  
> 背景：本地集市列表、店铺详情「点单 / 商家」Tab 中，多处出现**灰色占位**或**空白图**，需确认**接口字段是否有值**以及**最终可访问的静态 URL**，便于区分是「字段为空」还是「地址错误 / 权限 / 跨域」。

---

## 1. 前端实际读取的字段（按页面位置）

### 1.1 店铺列表 `GET /api/v1/market/shops`（每条 list 项）

| 截图位置 | 前端用途 | 读取字段（按优先级） |
|----------|----------|----------------------|
| 列表左侧**店铺缩略图**（与详情 Logo 同源） | `normalizeMarketShop` → `coverUrl` | `pickMarketShopAvatarPath`：`flatten` 合并 `shop`/`store` 嵌套后，**优先** `logo_url` / `logoUrl` / `logo` / `avatar` 等，再回退 `cover_url` / `coverUrl` / `list_cover_url` 等（经 `imgUrl()`） |

说明：**以上字段都为空或 null** 时，前端 **`coverUrl` 为空字符串**，表现为**灰块**。  
**若列表接口不返回任何 logo 类字段、只返回 `cover_url`，而详情接口有 `logo_url`，则列表仍会显示封面、详情显示 Logo——两处必然不一致；请列表与详情对同一店铺返回一致的 `logo_url`（或与详情相同的别名）。**

---

### 1.2 店铺详情 `GET /api/v1/market/shops/:shopId`

| 截图位置 | 前端用途 | 读取字段 |
|----------|----------|----------|
| 顶部**大横幅/封面** | `shop.cover` | `cover_url` 或 `cover` |
| 卡片左侧**店铺 Logo** | `shop.logo` | `pickMarketShopAvatarPath`（与列表缩略图同序：`logo_url` → `logo` → 封面类字段回退） |
| 「商家」Tab → **店铺照片**左图 | `shop.facadeImage` | `facade_image` |
| 「商家」Tab → **店铺照片**右图 | `shop.interiorImage` | `interior_image` |
| 「商家」Tab → **资质证照**大图 | `shop.licenseImage` | `license_image` |

以上字段在 `market-shop.js` 的 `loadShopFromApi` 中映射；若接口无值，会落到本地占位路径，但若占位仍异常，请一并核对。

---

### 1.3 店内商品 `GET /api/v1/market/shops/:shopId/goods`

| 截图位置 | 前端用途 | 读取字段（按优先级） |
|----------|----------|----------------------|
| 商品行**小图** | `buildGoodsGroups` 每条商品 | `main_image` → `image` |

---

## 2. 请后端协助的排查方式（建议）

1. **对当前测试店铺**（如「母婴生活馆官方店」）在**响应 JSON 里**确认上述字段是否存在、是否为**非空字符串**。
2. 请在**服务端日志或管理端**把下列 **最终静态地址**打印出来（或导出一张表），方便前端在浏览器直接打开核对是否为预期图片：  
   - 列表：`cover_url`（及实际用于列表的那一项）  
   - 详情：`cover_url` / `logo_url`（或 `cover` / `logo`）  
   - 详情：`facade_image`、`interior_image`、`license_image`  
   - 商品：`main_image`（或 `image`）
3. 若字段有值但仍是灰块，请核对：  
   - URL 是否 **https**、是否需 **登录态** 才能访问；  
   - 路径是否为**相对路径**（前端会拼 `imageBaseUrl`，需与线上资源一致）；  
   - 小程序**下载域名白名单**是否已配置该域名。

---

## 3. 前端拼接说明（便于后端对照）

相对路径会经 `utils/util.js` 的 `imgUrl()` 与 `config.imageBaseUrl` 拼接；**空值不会拼接**，列表封面会直接为空。
