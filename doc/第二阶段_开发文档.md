## 1. 当前完成进度
本次基于微信朋友圈的交互逻辑设计，支持用户头像、背景图、多图上传、时间倒序帖子流以及点赞和评论的嵌套展示。

- [x] 修改 `Users` 表结构，新增了 `bg_image` 字段（用于保存个人主页的背景图）。
- [x] 创建 `Posts` 表结构，用于保存帖子内容、作者信息和本地图片的存放路径 (`images` JSON 数组)。
- [x] 创建 `Comments` 表结构，支持帖子关联与用户自关联回复 (`reply_to_user_id`)。
- [x] 创建 `Likes` 表结构，记录用户与帖子的点赞关系。
- [x] 配置 `multer` 实现多图片直接上传至本地 `backend/uploads` 目录（限制为图片格式，单卡 5MB 上限）。
- [x] 实现了核心社区接口：
  - `GET /api/v1/posts`：获取所有社区帖子（朋友圈信息流，附带点赞人和评论内容，按时间倒序）。
  - `POST /api/v1/posts`：发表新帖子（支持一键上传发文字+最多 9 张配图，需授权）。
  - `POST /api/v1/posts/:postId/like`：对帖子进行点赞/取消点赞的 Toggle 接口。

- [x] 将对应的 API 路由 `postRoutes` 挂载到了主服务。

## 2. API 接口指引 (测试或前端联调时使用)

### 2.1 获取社区列表 (获取朋友圈)
**请求:** `GET http://localhost:3000/api/v1/posts?page=1&limit=10`
*返回包含发帖人(头像昵称)、帖子内容图片、包含点赞者列表、包含底下评论信息的巨型 JSON。*

### 2.2 发布新帖子 (类似发朋友圈)
**请求:** `POST http://localhost:3000/api/v1/posts`
**Headers:** `Authorization: Bearer <您的 token>`
**Body (form-data 格式):** 
- `content` (text): 文字内容
- `location` (text): 发帖位置 (可选)
- `images` (file): 选择多张图片 (最多9张)

### 2.3 点赞操作
**请求:** `POST http://localhost:3000/api/v1/posts/{帖子ID}/like`
**Headers:** `Authorization: Bearer <您的 token>`
*此接口为 Toggle 开关，点一次赞，再请求一次取消赞。*

### 2.4 发评论
**请求:** `POST http://localhost:3000/api/v1/posts/{帖子ID}/comment`
**Headers:** `Authorization: Bearer <您的 token>`
**Body (JSON):**
```json
{
  "content": "下次我家也要修",
  "reply_to_user_id": null // 如果是回复某人，填那个人的 user_id。如果是直接评论帖子填 null 即可
}
```
