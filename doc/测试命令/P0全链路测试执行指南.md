## 二、问题修复记录

### 2.1 登录接口路径问题 【已修复 ✓】

**修复日期**: 2026-04-24

**现象**: 测试脚本使用 `/api/v1/auth/wechat/login` 返回 404 错误

**原因分析**: 
- 后端文档中登录接口是 `/api/v1/auth/login`
- 测试脚本使用了 `/api/v1/auth/wechat/login`（路径不匹配）

**修复内容**:
- ✓ 修改测试脚本 `tests/test-p0-full-link.js`
- ✓ 将所有 `/api/v1/auth/wechat/login` 改为 `/api/v1/auth/login`（共 4 处）
- ✓ 添加手动 Token 配置选项，支持绕过微信 code 验证

**验证结果**: 接口返回 JSON 格式错误（不再是 HTML 404 页面），路径修复成功

## 六、常见问题排查

### 6.1 后端服务无法连接

```bash
# 检查服务是否运行
ssh cw@192.168.110.50 "ps aux | grep node"
ssh cw@192.168.110.50 "netstat -tlnp | grep 3001"

# 重启服务
ssh cw@192.168.110.50 "cd /home/cw/a/community-backend/backend/ && pm2 restart all"
```

### 6.2 数据库连接失败

```bash
# 检查数据库
ssh cw@192.168.110.50 "mysql -u root -p'CommunityPwd123!' community_db -e 'SELECT 1;'"

# 检查数据量
ssh cw@192.168.110.50 "mysql -u root -p'CommunityPwd123!' community_db -e '
SELECT 
  (SELECT COUNT(*) FROM Users) as users,
  (SELECT COUNT(*) FROM neighbor_assist_orders) as assist_orders,
  (SELECT COUNT(*) FROM market_orders) as market_orders,
  (SELECT COUNT(*) FROM service_orders) as service_orders;
'"
```

### 6.3 接口返回 404

1. 检查后端路由配置
2. 对照 API 文档确认路径
3. 查看后端日志
4. 重启后端服务

### 6.4 接口返回 401

1. 检查 token 是否有效
2. 重新登录获取新 token
3. 检查 Authorization header 格式
