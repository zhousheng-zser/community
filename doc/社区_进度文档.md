# “社区” 模块进度文档

## 整体进度概览
“社区”功能是本项目用来增加用户粘性和促活的核心业务模块（包含类朋友圈的发文、发图、点赞及评论）。
该模块**进度极高，前后端已经全链路跑通**，从 UI 展示到底层数据库记录均已打通并稳定服务。

## 前端开发进度 (已完成)
- **核心UI与交互**：
  - 构建了顶部“附近圈子”入口、搜索栏和分类 Tab 切换（“热门话题”、“热门活动”、“邻里互动”）。
  - 支持发帖流，涵盖用户头像、时间展示、文本和九宫格图片墙（采用自动适应排列样式），并拥有阅读量、评论数、点赞数的元数据。
  - **右下角发帖悬浮窗**：引导用户进入发帖专页 (`/pages/community-publish/community-publish`)。
  - **动态评论面板**：实现了带有关闭、软键盘避让防遮挡的悬浮输入框。
- **与后端接口的联动 (已通)**：
  - 获取帖子：列表主动抓取 `util.get("/posts")`，并附带了请求类目参数及分页。并在前端自动给相对路径图片拼接了服务器主机地址，规避了破图问题。
  - 点赞动作：对接 `util.post("posts/${id}/like")`，实现了点赞和取消操作的前端状态乐观更新。
  - 发评论（图文混合）：成功对接 `util.post("posts/${postId}/comment")`。并在评论前加入了先上传图片 `util.uploadFile` 获取正确 URL 的强流程，完美遵守了 2026 年要求的新安全指引。

## 后端开发进度 (已完成，经过 Bug 修复)
后端社区相关 API 已涵盖在最初的 **第二阶段** 和 **第四阶段附加需求** 当中，经过近期的 Bug 修理已非常健全：
- **公共列表接口**：`GET /api/v1/posts/` 已提供。
- **创建帖子**：`POST /api/v1/posts/`。近期（2026-03-12）已经修复了字段遗漏的问题，将前端发来的 `category` 字段存入数据库中，保证了分类过滤的有效性。
- **点评赞接口**：
  - 点赞/取消点赞 (`POST /api/v1/posts/:postId/like`)
  - 发表评论 (`POST /api/v1/posts/:postId/comment`)，已通过 2026年6月迭代在数据库中扩展了 `image_urls` 字段，专门承接带图片的富文本评论。

## 联调及后续关键事项
1. 社区页面目前一切运转良好，前端的图片拼接策略和提交策略完全符合后端的硬性规定。
2. 留下了小瑕疵但无伤大雅：用户头像如果未能拉到（后端关联出错时），前端设有一个兜底默认头像保障视觉展示。
