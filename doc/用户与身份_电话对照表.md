# 用户与身份 · 电话号码对照说明

> **数据来源**：`community_db` 库表 `Users`、`worker_applications`、`worker_profiles`、`service_provider_profiles`、`merchant_accounts`、`market_shops`。  
> **更新方式**：数据会随环境变化；需要最新清单时可在 `backend` 目录执行下方脚本重新导出。

---

## 1. 身份判定规则

| 身份 | 判定条件（满足其一即标注） |
|------|---------------------------|
| **技工** | `worker_applications.status = 'approved'`，或 `worker_profiles.status = 'active'`（与技工门户登录校验一致）；或与 `Users.role = 'worker'` 合并统计。 |
| **到家服务商** | 存在 `service_provider_profiles` 且 `user_id` 对应该用户。 |
| **普通用户** | 不同时满足上述技工 / 服务商条件。 |
| **集市商户** | 以 **`merchant_accounts`** 为准，用于商家 Web 后台登录；**登录名 `username` 往往不等于 `Users.phone`**，无法与小程序用户表一行严格对齐，见第 3 节。 |

## 4. 各端登录密码 / 验证码（对照本仓库与环境）

> **安全**：以下为**开发 / E2E 环境**常用固定口令。**生产环境必须修改**，且勿将真实密码写入版本库。

| 入口 | 账号形式 | 密码或验证码 | 说明 |
|------|----------|--------------|------|
| **小程序 C 端** | 微信 openid | 无（微信 `code` 换会话） | `Users` 无登录密码字段 |
| **技工后台 Web** `worker-portal/login` | `Users.phone`（须为已审技工） | **验证码**：默认 `123456`；或 `WORKER_PORTAL_SMS_CODE` | 非密码登录 |
| **集市商家后台** `merchant-portal/login` | §3 表 `username` | **`e2e_pass_123`** | 见 §3 |
| **到家服务商中台** `service-provider-portal/login` | `sp_demo` | **`sp_demo123`** | `seed-service-provider-portal-demo-account.js` 默认 |
| **到家服务商中台** `service-provider-portal/login` | `sp_e2e_*`（库中多条） | **`e2e_sp_portal_123`** | `e2e-cw-fullflow.js` 创建门户账号时使用的密码 |
| **平台运营后台 admin** | 见环境变量 | 见环境变量 | **`backend/.env`**：`ADMIN_USERNAME` / `ADMIN_PASSWORD`（**勿对外泄露**） |

## 5. 本地重新生成对照数据

在配置好 `backend/.env` 中 `DB_*` 后执行：

```bash
cd backend && node scripts/export-user-identity-table.js
```

stdout 为 TSV：先按手机号输出「身份、昵称样例」，再输出「仅商户登录名」与店铺电话。可将结果粘贴回本文 **§2 / §3** 以作变更记录。
