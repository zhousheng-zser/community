## 2. 待完成步骤 (等待开发者操作)
由于当前环境中没有全局安装 MySQL 服务（或没有注册到环境变量），无法由代码自动创建数据库。

### 开发者需要手动执行的数据库操作：
1. 确保您的电脑上已经安装并运行了 **MySQL**。
2. 打开您的数据库管理工具（如 Navicat, DataGrip 或是 MySQL 命令行）。
3. 执行以下 SQL 语句来创建我们项目所需的空数据库：
   ```sql
   CREATE DATABASE IF NOT EXISTS community_db DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
4. 打开项目中的 `backend/.env` 文件。
5. 将 `DB_PASSWORD` 的值修改为您本地真实的 MySQL `root` 账户密码。
