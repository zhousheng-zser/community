# “我的” 模块进度文档

## 整体进度概览
“我的”页面是社区小程序的个人中心枢纽。包含了个人信息展示、账户资金概览，并集合了全平台所有的二级订单和管理入口。
**进度表现为 UI 全面竣工，头部核心数据获取和身份校验后端打通，其余宫格导航已做好埋点及扩展预留。**

## 前端开发进度
- **头部身份模块**：
  - 动态展示头像和修改通道（进入编辑页）。
  - 基于全局缓存加载用户标签（普通用户、管理员、推客）、手机号码脱敏（中间四位掩蔽），及展示基本积分。
  - 引入了服务端拉取账户余额与可用优惠券的请求，保障财产类敏感数据的准确获取。
- **钱包收益栏**：
  - 设计了横宽版式的可提现钱包入口，点击直达账户体系。
- **六大板块集合**：
  - 我的订单：服务订单、集市订单、推客等。
  - 我的社区：我的帖子、点赞及其跳转（利用 URL 传参过滤同源列表页）。
  - 加入九州社区（非常关键）：技工入驻、服务商入驻、集市商家。
  - 其他服务：地址管理、反馈、设置。
  - **交互进度**：除了少部分未开发的新功能接入了封装的 `showToastWait` (“敬请期待”)，超 60% 的主要入口已可流转路由。

## 后端开发进度 (功能多线并行实现度高)
用户的多套体系在后端的接发支持已经就绪，见 `API接口文档` 中的：
- **认证模块**：基础注册/登录体系稳固。更新个人资料包含头像和图片的复杂提交接口也已在 `/api/v1/user/profile` 中提供支持。
- **余额优惠券体系**：为兼容旧版本的个人信息查询：`/api/v1/acount/info` 及 `/api/v1/wx/user/coupon/:id` 予以了长效的支持。
- **入驻认证模块**：于 2026 年底最新补齐的三大建表和三大入驻提交入口 —— 技工 (`/api/v1/worker/apply`)、服务商 (`/api/v1/service-provider/apply`)、集市 (`/api/v1/market/apply`) 均已全部测试可用（支持照片与特殊字段防错防空拦截）。
- **用户外延模块**：如意见反馈提交、我参与的活动获取、我的各种交互（关注、各种角色下的订单），分别在用户域和各业务域下存在响应点。

## 联调及后续关键事项
1. 各板块入口的完善：“敬请期待”的导航要伴随其他业务前端页面的落实逐批替换真实的 Navigator 网址。
2. 管理后台的支持：管理后台端需要持续对由“我的”页面中发出的各类入驻进行审核支持（如对应的 `PUT /api/v1/admin/worker-applications/:id` 等），保持平台整体流转的闭环。
